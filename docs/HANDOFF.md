## 4. 快速上手

```bash
git log --oneline -5                            # 最近做了什么
pnpm test && pnpm build && pnpm tools validate  # 验证基线
pnpm build && pnpm start                        # 起服务端（默认 3000）
python3 -m http.server 5173 --bind 127.0.0.1    # 起静态页（另开终端）
# 浏览器打开 http://localhost:5173/assets/html/index.html → ws://localhost:3000 → 连接
```

- 旧档（缺 level 字段）会被新构建拒绝读——删/改名 `data/saves/*.json` 后重启即可。
- 页面须跑在 `http://localhost:5173`（服务端 CORS 默认放行该源）。
- 协议细节见 `docs/CLIENT-INTEGRATION.md`；schema 变更后跑 `pnpm schema:gen` 并 `pnpm schema:check` 校验。
